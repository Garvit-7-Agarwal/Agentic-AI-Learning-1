In the first file of this repository, named 1_bmi_workflow.ipynb, I understood the fundamentals of LangGraph—including how to construct a graph by adding nodes and edges, how to define and integrate functions within the workflow, and how state is managed and utilized in LangGraph.
In the second file, named 2_simple_llm_workflow, I learned how to integrate LangGraph with an LLM. This is a simple question-answer based LLM program where I understood how different nodes connect, how the workflow passes information between them, and how LangGraph structures LLM interactions internally.
